# Codex 컨텍스트 보존: 팀 인수인계

- 목표: 계획·결정·검증·다음 행동을 파일에 기록하고 새 세션/압축 후 다시 읽는다. 기록하지 않은 대화의 무손실 복원은 보장하지 않는다.
- 도구: planning-with-files v3.27.0, upstream b6580cd24af1d8a95ab268794456e05608a1afd3. 출처·MIT 라이선스·원본 해시는 upstream-lock.json에서 확인한다.
- 소유권: 게임 코드·공유 Codex 구성·AGENTS·팀 문서는 기존 Dev Git, 에셋·프로젝트 데이터는 P4다. Markdown은 P4 제외이며 개인 계획은 두 저장소 모두 제외한다.
- 상태 분리: `.planning/<ID>/`는 개인 작업 기록, `Saved/LMContext/Sessions/`는 대화별 로컬 바인딩이다. 팀에 필요한 결정만 이 Team 폴더에 검토하여 요약한다.
- 복구: Windows 연결기는 명시한 작업만 선택한다. 바인딩이 없거나 잘못됐으면 다른 사람의 과제를 추측하지 않는다. 압축/재개 후 해당 세 기록을 전체 읽고 실제 변경과 대조한다.
- 기록 시점: 수정·검증·결정 직후 갱신한다. PreCompact 안내는 저장 완료 보장이 아니다.
- 검증: 기반 구성은 20개 Windows 훅 모의 검사와 원본 해시·줄바꿈·반복 체크아웃 검증을 통과했다. 모의 검사와 실제 Codex의 신뢰 승인·/compact 검증은 구분한다.
- 남은 확인: 각 사용자의 `/hooks` 출처 검토·신뢰 승인과 실제 `/compact` 복원 대조. 검증하지 않은 앱 동작을 성공으로 기록하지 않는다.
- 팀원 사용: Git 버전을 받은 뒤 Lumia.uproject 폴더에서 Codex를 열고 README.ko.md를 따른다. 개인 계획/바인딩은 새로 만든다.
- 공통 유지보수: 도구 변경은 관련 경로만 별도 브랜치에서 검토한다. 자동 업데이트·외부 업로드·신뢰 우회는 없다.
